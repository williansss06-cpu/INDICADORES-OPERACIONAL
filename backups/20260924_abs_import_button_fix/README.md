# Ajuste dos botões de importação — 2026-09-24

O alerta `Use colunas: mes;indicador;valor` pertence ao importador global do Plano de Sustentação, não à planilha de Absenteísmo.

Nesta versão, o importador global de indicadores fica oculto enquanto a aba de Absenteísmo está ativa. O usuário deve usar exclusivamente `Importar planilha de Absenteísmo`, que aceita a planilha combinada e separa as operações pela coluna `SETOR/Operação`.
