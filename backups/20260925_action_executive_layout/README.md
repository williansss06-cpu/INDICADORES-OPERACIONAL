# Backup — Layout executivo do Plano de Ação

Este diretório preserva o `index.html` anterior à reorganização visual da tabela de Planos de Ação.

A alteração é somente de UX/UI no frontend. A entrega mantém o mesmo Supabase, tabela `sustentacao_plano_acao`, IDs, histórico, notificações, portal externo, Storage privado, salvamento automático, permissões e RLS.

A nova apresentação inclui indicadores resumidos, badges de status e prioridade, menu contextual de controles e drawer lateral de detalhes. Nenhuma migration ou dado operacional foi alterado.
