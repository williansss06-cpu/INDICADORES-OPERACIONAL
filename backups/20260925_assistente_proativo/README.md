# Backup — Assistente de Gestão proativo

Este diretório preserva o `index.html` anterior à integração da saudação proativa do Assistente de Gestão.

A alteração adiciona somente um card compacto no canto inferior direito, sugestões condicionadas às permissões existentes, estado por sessão/login e atualização silenciosa do contexto quando a tela ou os dados mudam. Não cria tabelas, não altera RLS, não altera cálculos, não envia dados automaticamente ao modelo e não modifica o contrato do Supabase.
